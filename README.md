### Project Overview

The project presents an interactive, browser-based dashboard for exploring synthetic analytical fields associated with a **pin-type PEM fuel-cell cathode flow field**.

It demonstrates:

- 🌬️ **Velocity magnitude** around nine pin obstacles
- 📉 **Pressure distribution** from inlet to outlet
- 💧 **Water mass-fraction development** through the flow field
- 🖥️ Responsive dark and light themes
- ⌨️ Keyboard navigation and automatic result cycling
- 📄 An accompanying educational fuel-cell truck case-study report
- 🚀 Static deployment using GitHub Pages

### Selected Dashboard Results

| Metric | Displayed Value |
| :--- | ---: |
| Mean inlet pressure | 150.0 kPa |
| Mean outlet pressure | 130.0 kPa |
| Overall pressure drop | 20.0 kPa |
| Mean velocity | 11.58 m/s |
| Velocity range | 0.00–13.50 m/s |
| Outlet water mass fraction | 0.850 |

> [!IMPORTANT]
> The displayed fields are synthetic analytical visualizations created for education, portfolio presentation, and discussion of post-processing concepts. They are not outputs from a validated Navier–Stokes or PEM multiphysics solver and should not be used for engineering certification or safety-critical decisions.
